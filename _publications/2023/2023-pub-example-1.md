title:          "MLA3DVG: Dual-modality multi-level semantic alignment for robust monocular 3D visual grounding"
selected:       true
pub:            "Pattern Recognition"
pub_date:       "2026"
abstract: >-
  Monocular 3D Visual Grounding (Mono3DVG) aims to localize objects in 3D space from natural language using only RGB images. We propose MLA3DVG, which explicitly decomposes and aligns multi-level scene, attribute, and spatial semantics across visual and textual modalities, enabling fine-grained cross-modal reasoning. Experiments on Mono3DRefer demonstrate state-of-the-art performance, particularly in challenging scenarios with long-range targets and multiple similar objects.
